# Tejas Sangle | Portfolio

A gamer-themed personal portfolio website built using only HTML and CSS (no JavaScript).

**Repository:** https://github.com/Tejas-Sangle-10/portfolio

## About

I'm Tejas, a student at Scaler School of Technology learning web development.
This portfolio is my first big build, made as part of the Builders Day project.
The design is inspired by video games: a sticky HUD-style navbar, a "player" hero,
a skill tree with unlocked and locked skills, and projects presented as quests.

## Features

- Sticky navigation bar with a CSS-only hamburger menu on mobile
- Hero section with a background image and animated text
- About section with a player-card layout
- Skill Tree built as an inventory grid, with hover details and locked slots
- Journey section with a CSS timeline
- Project cards with hover effects
- Contact section with GitHub, LinkedIn and Gmail links
- Fully responsive on mobile, tablet and desktop

## Technologies

- HTML (semantic elements)
- CSS (Flexbox, Grid, positioning, media queries, transitions, keyframe animations, CSS variables)
